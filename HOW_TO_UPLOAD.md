# HomePilot is already on this repo

Clone and run:

```bash
git clone https://github.com/Jatin-UoD/amazon.git
cd amazon
npm install
npm run dev
```

Demo sign-in: `jatin@example.com` and any password of 4 or more characters.

`COMMIT_MESSAGES.md` explains what each source file does.

Electricity, water, and Ring events in this build are simulated. No Ring secret is stored in the repo.
